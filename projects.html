Project 2 - Configuration

During the final weeks of Networking II, we were given a final project to be completed in groups. This project had us configure multiple switches and routers so that each PC were able to successfully ping to it. Some challenges included: configuring all switches and routers, verifying OSPF and BGP neighbors and successfully configuring VLAN trunks.
